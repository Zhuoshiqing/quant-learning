# quant-learning

我的量化金融 Python 学习仓库，记录从环境搭建到量化实战的练习代码。

## 环境

- Anaconda（安装在 `E:\anaconda3`）
- conda 环境：`quant`（Python 3.11）
- 核心库：numpy、pandas、matplotlib、scipy、statsmodels、scikit-learn、jupyterlab
- 数据与建模：akshare、tushare、baostock、lightgbm、arch

## 学习路线

1. 阶段 0：环境搭建（Anaconda + Jupyter + VSCode + Git）
2. 阶段 1：Python 基础
3. 阶段 2：NumPy / Pandas / Matplotlib 三件套
4. 阶段 3：统计与计量建模
5. 阶段 4：量化数据获取与策略回测
6. 阶段 5：机器学习
7. 阶段 6：工程化与求职
